# MyPatterns 命令清单

以下命令在 Windows PowerShell 中运行。每打开一个新终端，先执行：

```powershell
cd D:\Mima\SonicSurface
```

所有示例使用完整的 Python 路径，不使用 `mp` 简写（PowerShell 已将 `mp` 用作 `Move-ItemProperty` 别名）。涉及硬件的示例以 **COM8** 为例；先用 `ports` 核对当前端口。板卡固件已内置相位校正，脚本发送原始相位；不要在上位机再做一次校正。

目录位置：入口脚本在 `MyPatterns/`；样例图与手势模型在 `MyPatterns/assets/`；图片算法在 `MyPatterns/image/`，三维算法在 `MyPatterns/geometry/`；预览图及其同名 JSON 在 `MyPatterns/results/previews/`，算法对照在 `MyPatterns/results/direct_comparison/`、`MyPatterns/results/gradient_comparison/`；摄像头快照、设置和标定在 `MyPatterns/results/hand_tracking/`；测试在 `MyPatterns/tests/`，原理说明在 `MyPatterns/docs/`。下方命令从仓库根目录运行。

## 1. 查看设备与帮助

```powershell
.\ultrasound_solver\.venv\Scripts\python.exe MyPatterns\my_patterns.py ports
.\ultrasound_solver\.venv\Scripts\python.exe -X utf8 MyPatterns\my_patterns.py --help
.\ultrasound_solver\.venv\Scripts\python.exe -X utf8 MyPatterns\my_patterns.py image --help
```

`-X utf8` 仅保证中文帮助文本在某些终端编码下能显示；普通发射命令不要求加它。

## 2. 基础声场

下列命令发送一帧相位后即退出，**设备会保持该图案发射**，直到发送 `off`：

| 功能 | 在 PowerShell 中输入 |
|---|---|
| 单焦点，中心、离阵 16 cm | `.\ultrasound_solver\.venv\Scripts\python.exe MyPatterns\my_patterns.py focus 0 0 --dist 0.16 --port COM8` |
| 涡旋，拓扑荷 2 | `.\ultrasound_solver\.venv\Scripts\python.exe MyPatterns\my_patterns.py vortex 0 0 --m 2 --dist 0.16 --port COM8` |
| 双阱，方向 90 度 | `.\ultrasound_solver\.venv\Scripts\python.exe MyPatterns\my_patterns.py twin 0 0 --angle 90 --port COM8` |
| 瓶形阱 | `.\ultrasound_solver\.venv\Scripts\python.exe MyPatterns\my_patterns.py bottle 0 0 --port COM8` |
| 两个焦点 | `.\ultrasound_solver\.venv\Scripts\python.exe MyPatterns\my_patterns.py points 0.03 0 -0.03 0 --dist 0.16 --port COM8` |
| 小角度波束偏转，8 度 | `.\ultrasound_solver\.venv\Scripts\python.exe MyPatterns\my_patterns.py steer 8 --port COM8` |
| 关闭所有通道 | `.\ultrasound_solver\.venv\Scripts\python.exe MyPatterns\my_patterns.py off --port COM8` |

`focus X Z`、`vortex X Z` 等的 `X`、`Z` 是阵面内的横向坐标，单位米；`--dist` 是离阵深度 `Y`，默认 0.16 m。`points` 的数字按 `X1 Z1 X2 Z2 ...` 成对输入，至少两点。

只想看一个图案的声场、不连接串口：

```powershell
.\ultrasound_solver\.venv\Scripts\python.exe MyPatterns\my_patterns.py focus 0 0 --dist 0.16 --dry --save MyPatterns\results\previews\focus_preview.png
```

## 3. 2D 图片

普通 `image` 默认使用阵列感知 **GS** 算法。可以输入常见图片文件，但细线、复杂背景可能模糊；`MSE` 是仿真目标与重建幅度的误差，不代表实际触觉质量。

```powershell
# 只计算 F 的相位并保存仿真预览，不连接设备
.\ultrasound_solver\.venv\Scripts\python.exe MyPatterns\my_patterns.py image MyPatterns\assets\demo_F.png --dry --save MyPatterns\results\previews\F_preview.png

# 发送 F；命令结束后设备保持发射，需要单独执行 off
.\ultrasound_solver\.venv\Scripts\python.exe MyPatterns\my_patterns.py image MyPatterns\assets\demo_F.png --port COM8

# 以 200 Hz 开关调制发射 F，持续 3 秒后关闭
.\ultrasound_solver\.venv\Scripts\python.exe MyPatterns\my_patterns.py image MyPatterns\assets\demo_F.png --mod 200 --dur 3 --port COM8
```

将图片路径替换成自己的 PNG/JPG 文件路径即可；路径含空格时加双引号。指定其他算法的方法是 `--method 名称`：

| 名称 | 作用 |
|---|---|
| `array` | 默认阵列感知 GS |
| `gradient` | GS 后做梯度精修 |
| `gradient_smooth` | GS 后精修，并进一步压低笔画起伏 |
| `backprop` | 单次反传，不用 GS，速度快但通常质量较差 |
| `direct` | 不用 GS，从反传初相直接优化 256 路相位 |
| `paper` | 论文中的连续口径方法，用于复现对照 |

示例：

```powershell
.\ultrasound_solver\.venv\Scripts\python.exe MyPatterns\my_patterns.py image MyPatterns\assets\demo_F.png --method gradient_smooth --dry --save MyPatterns\results\previews\F_smooth.png
.\ultrasound_solver\.venv\Scripts\python.exe MyPatterns\my_patterns.py image MyPatterns\assets\demo_F.png --quant-refine --dry
```

`--quant-refine` 是可选的 32 档量化后微调：逐通道尝试 ±1 档，只有图像目标函数改善且弱笔画/背景约束通过才接受。默认关闭，本机一次约 44–50 ms；dry run 会打印微调前后分数与接受次数。可加 `--flipx`、`--flipz`、`--transpose` 调整图案方向；`--iters 50` 调整 GS 迭代次数；`--dist 0.16` 指定目标平面深度。

## 4. 多深度图片

`image3d` 至少需要两组 `--layer 图片 深度`。默认 `sequential`：每层分别用 2D GS 算出一帧，轮流发送，**并非同一时刻生成两张立体图片**。

```powershell
# 离线预览 F@12 cm、A@16 cm；输出 PNG 和同名 JSON 指标
.\ultrasound_solver\.venv\Scripts\python.exe MyPatterns\my_patterns.py image3d --layer MyPatterns\assets\demo_F.png 0.12 --layer Algorithms\EmissionPhasesAmpsForTargetSlice\A.png 0.16 --dry --save MyPatterns\results\previews\image3d_sequential.png

# 实物逐层播放 3 秒，20 fps，到时自动关闭
.\ultrasound_solver\.venv\Scripts\python.exe MyPatterns\my_patterns.py image3d --layer MyPatterns\assets\demo_F.png 0.12 --layer Algorithms\EmissionPhasesAmpsForTargetSlice\A.png 0.16 --fps 20 --dur 3 --port COM8

# 单帧同时优化两个平面的实验模式；目前串扰较重，先只做仿真
.\ultrasound_solver\.venv\Scripts\python.exe MyPatterns\my_patterns.py image3d --layer MyPatterns\assets\demo_F.png 0.12 --layer Algorithms\EmissionPhasesAmpsForTargetSlice\A.png 0.16 --mode static --steps 160 --dry --save MyPatterns\results\previews\image3d_static.png
```

`sequential` 不支持 `--mod`；逐层切换完整相位帧没有 200 Hz 触觉调制。`static` 虽能产生一组同时作用于两个深度的相位，但目前仿真质量不理想。

## 5. 3D 水杯与网格模型

`cup3d` 的默认轮廓由 24 个焦点组成：杯底 10 cm、杯口 16 cm、杯口半径 3 cm；**一次只聚焦一个点**。

```powershell
.\ultrasound_solver\.venv\Scripts\python.exe MyPatterns\my_patterns.py cup3d --dry --save MyPatterns\results\previews\cup3d_preview.png
.\ultrasound_solver\.venv\Scripts\python.exe MyPatterns\my_patterns.py cup3d --bottom 0.10 --top 0.16 --radius 0.03 --fps 20 --dur 3 --port COM8
```

用 `--rim-points 8`、`--base-points 8`、`--wall-levels 2` 改变扫描点数。默认 24 点、20 fps 扫一圈至少 1.2 秒，正常结束自动关闭。

`mesh3d` 读取 **STL、OBJ、PLY** 网格；模型需以 Z 轴朝上，程序把模型缩放到指定尺寸，并从边缘或表面挑选稀疏焦点。需要当前虚拟环境安装 `pyvista`（本机已安装）。

```powershell
# 用仓库中现有 STL 做离线预览
.\ultrasound_solver\.venv\Scripts\python.exe MyPatterns\my_patterns.py mesh3d "Mech\two arrays support\leg.stl" --near 0.10 --width 0.06 --height 0.06 --points 24 --dry --save MyPatterns\results\previews\mesh3d_preview.png

# 换成自己的 STL 文件；限时播放后自动关闭
.\ultrasound_solver\.venv\Scripts\python.exe MyPatterns\my_patterns.py mesh3d "D:\MyModels\cup.stl" --near 0.10 --width 0.06 --height 0.06 --points 24 --fps 20 --dur 3 --port COM8
```

`--near` 是模型最低点的离阵距离；`--width`、`--height` 是允许的最大横向宽度和竖直高度，单位都是米。`--points` 可取 8 到 120；点越多，一圈越久。还可用 `--feature-angle 40` 控制锐边提取阈值。两种 3D 扫描目前都没有 200 Hz 调制或手部追踪；预览的热图是**多帧时间平均**，不能理解为同一时刻有一个完整实体物体。

## 6. 限时触觉、持续调制与实时调节

```powershell
# 200 Hz、70% 占空比调制焦点，持续 3 秒；正常结束自动关闭
.\ultrasound_solver\.venv\Scripts\python.exe MyPatterns\my_patterns.py burst 0 0 --kind focus --dist 0.12 --freq 200 --duty 0.7 --dur 3 --port COM8

# 50 ms 短脉冲，连续 3 次；正常结束自动关闭
.\ultrasound_solver\.venv\Scripts\python.exe MyPatterns\my_patterns.py tap 0 0 --kind focus --dist 0.12 --pulse 0.05 --count 3 --gap 0.3 --port COM8

# 持续调制，按回车结束并关闭
.\ultrasound_solver\.venv\Scripts\python.exe MyPatterns\my_patterns.py hold 0 0 --kind trap --dist 0.12 --freq 100 --duty 0.7 --port COM8

# 交互调节台，按回车退出并关闭
.\ultrasound_solver\.venv\Scripts\python.exe MyPatterns\my_patterns.py live 0 0 --kind focus --dist 0.12 --freq 100 --duty 0.7 --port COM8
```

`--kind` 可选 `focus`（焦点）、`trap`（带轴向零点的焦点）、`vortex`、`twin`、`bottle`。`live` 中方向键上下调频率、左右调占空比；小写 `w/s` 移动 X，`a/d` 移动 Z，`r/f` 调深度；数字 `1` 至 `5` 切换图案。`hold` 和 `live` 会保持进程运行并占用串口。

以下动画持续运行，**在原窗口按 Ctrl+C** 停止并关闭发射：

`orbit` 绕圆轨道移动焦点；`scan` 横向往返；`mpx` 在两组多焦点间切换；`images` 轮播多张 GS 图片，每张默认保持约 2 秒。`spin` 只改变涡旋整体相位，**不会使声强图实际旋转**。`anim --dry` 不生成动画预览，仅跳过硬件发送。

## 9. 参数和停止方式

| 参数 | 意义 |
|---|---|
| `--port COM8` | 当前设备串口；用 `ports` 先确认 |
| `--dist 0.16` | 目标面离阵深度，米；主要用于 2D/焦点命令 |
| `--dry` | 只计算，不连接串口；适合 `focus`、`image`、`image3d`、`cup3d`、`mesh3d` |
| `--save 路径.png` | 保存仿真图片；不适用于 `anim` 实时序列 |
| `--preview` | 弹出静态声场预览窗口 |
| `--axis y`、`x`、`z` | 静态单帧声场预览切面；`y` 为俯视，`x/z` 为侧视 |
| `--fps 20` | 动画/3D 每秒发送的相位帧数，**不是** 40 kHz 载波或 200 Hz 调制频率 |
| `--dur 3` | 限时播放秒数；只对支持限时的命令生效 |

- `focus`、`vortex`、`twin`、`bottle`、`points`、`image`（不带 `--mod`）、`image3d --mode static`（不带 `--mod`）、`steer`：发送后持续发射，运行 `off --port COM8` 关闭。
- `burst`、`tap`、`image --mod`、`image3d` 分时、`cup3d`、`mesh3d`：正常播放到时后关闭。
- `hold`、`live`：在原窗口按回车；`anim`、`freq_sweep.py`：在原窗口按 Ctrl+C。若原进程还占用 COM8，另开终端执行 `off` 可能无法打开串口。
- `off --dry` 不会关闭设备。若 USB/COM 断联或串口写入超时，程序发出的关闭命令也可能无法到达板卡；不能将日志中的“关闭”当作硬件已停发的证明。

## 10. 手部指尖跟踪（hand_track.py）

依赖 `opencv-python`、`mediapipe`；RealSense 模式还需 `pyrealsense2`，这些包已安装在 `.venv`。默认目标是食指尖 `index_tip`（MediaPipe 第 8 点），也可用 `--target palm|thumb_tip|middle_tip|ring_tip|pinky_tip`。画面上的红圈为目标点、绿色覆盖层为由关键点生成的近似手形 mask，不是逐像素深度分割。

相机竖放在阵列旁向上拍摄；先用 `camtest` 确认红圈稳定落在食指尖。以阵列中心为 (0,0,0)，`y` 是垂直阵列面的高度。用尺子在 10 cm 与 15 cm 两个高度各准备 3x3 点，`x/z` 都是 -6、0、+6 cm，合计 18 点。每个 `x/z` 位置连续测 10 cm、15 cm，再移动到下一处；停稳后按空格采样（`r` 重采，`q` 放弃）。按 `V` 在彩色、深度、并排预览之间切换,确认指尖标记处的深度有效。每对显示的相机三维两点直线距离不用于自动重采；相机与阵列不平行由最终三维标定处理。移动相机、改变分辨率后必须重标：

```powershell
.\ultrasound_solver\.venv\Scripts\python.exe MyPatterns\hand_track.py calibrate --realsense --target index_tip --dist 0.10 --height-step 0.05
```

标定结果存 `MyPatterns\results\hand_tracking\hand_track_calib_3d.json`，包含相机到阵列的三维变换、目标手指和残差。RMS 大于 10 mm 或最大误差大于 20 mm 时不保存。旧二维标定 `hand_track_calib.json` 原样保留，但三维跟踪不接受它。
若超标，终端会列出各点残差，并保存 `hand_track_calib_3d_diagnostic.json` 供定位错点。采样时请确认尺量高度是**食指尖到阵列面**的距离，红圈处 `depth` 稳定；相机到指尖的 `depth` 不是阵列高度 `y`。

若只做短时中心区域试验,诊断数据可用 `--experimental` 明确加载。它重新计算残差并限制 RMS ≤15mm、最大 ≤30mm、`focus`、中心 x/z 默认 ±3cm、y 9-16cm、占空比 ≤0.2、丢手 0.2s 关断、20s 自动结束。实验模式默认 2mm 相位更新死区;要测试横向跟随可加 `--experimental-span 0.05` 扩大到 ±5cm。检查整块阵列可显式用 `--experimental-span 0.08 --experimental-height 0.08 0.18`,但边缘超出了原标定采样范围,须先 dry run 核对。正式标定门槛不变。确认相机仍识别为原 D405,再连板:

```powershell
.\ultrasound_solver\.venv\Scripts\python.exe -X utf8 MyPatterns\hand_track.py track --realsense --experimental --dry --duty 0.2 --max-seconds 10
.\ultrasound_solver\.venv\Scripts\python.exe -X utf8 MyPatterns\hand_track.py track --realsense --experimental --port COM8 --duty 0.2 --max-seconds 20
```

| 功能 | 在 PowerShell 中输入 |
|---|---|
| 只看三维坐标，不连板 | `.\ultrasound_solver\.venv\Scripts\python.exe MyPatterns\hand_track.py track --realsense --dry` |
| 正式跟踪，200 Hz 调制 | `.\ultrasound_solver\.venv\Scripts\python.exe MyPatterns\hand_track.py track --realsense --port COM8` |
| trap 图案跟随 | `.\ultrasound_solver\.venv\Scripts\python.exe MyPatterns\hand_track.py track --realsense --kind trap --port COM8` |
| 合成圆路径离线回路，无需摄像头 | `.\ultrasound_solver\.venv\Scripts\python.exe MyPatterns\hand_track.py track --sim --dry` |
| 离线单元测试 | `.\ultrasound_solver\.venv\Scripts\python.exe -X utf8 -m unittest discover -s MyPatterns/tests -t MyPatterns -p "test_hand_track.py" -v` |

手指关键点或深度丢失超过 0.5 s、`x/z` 越过 ±8 cm 或 `y` 不在 7-20 cm 时静默；`Ctrl+C` 或预览窗口按 `q` 退出并关发射。真实 D405 对齐双流已出图；三维标定与上板效果尚未实测。先用 `--dry` 上下移动食指，确认 `y` 变化方向和量级，以及 `x/z` 方向，再连板。

摄像头画面过暗或"变焦过高"时，先跑 `camtest` 用键盘整定再标定（设置存 `MyPatterns\results\hand_tracking\hand_track_cam.json`，`calibrate`/`track` 自动套用；改分辨率/变焦后需重新标定）：

```powershell
.\ultrasound_solver\.venv\Scripts\python.exe MyPatterns\hand_track.py camtest --cam 0
```

按键：`W/S` 曝光、`A/D` 亮度、`Q/E` 增益、`-`/`=` 变焦、`X` 自动曝光开关、`R` 循环分辨率（画面"变焦过高"多是 640x480 裁切，切到 1280x720 即恢复全视场）、`P` 打印参数、`ESC` 保存退出。画面显示 `index_tip=OK` 才表示检测到了目标手指。

机器带内置摄像头时 `--cam 0` 常是内置前置，外接 USB 相机要先用 `cams` 找索引（每台能打开的相机在 `MyPatterns\results\hand_tracking\cam_<后端>_<索引>.png` 留一张快照，看图认机）：

```powershell
.\ultrasound_solver\.venv\Scripts\python.exe MyPatterns\hand_track.py cams
```

找到索引后，`camtest` / `calibrate` / `track` 都用同一个 `--cam N`。

### RealSense D4xx 相机

当前设备为 RealSense D405，提供彩色 BGR8 和深度 Z16。普通 `camtest` 单开彩色流；加 `--depth`/`--pointcloud` 后也会开启深度并对齐到彩色画面，`calibrate`/`track` 同样使用对齐双流。之前曾遇到 `hwmon command ... response -9`；若再次出现，请检查设备占用/连接并用 RealSense Viewer 对照。

```powershell
.\ultrasound_solver\.venv\Scripts\python.exe -X utf8 MyPatterns\hand_track.py camtest --realsense --target index_tip
.\ultrasound_solver\.venv\Scripts\python.exe -X utf8 MyPatterns\hand_track.py camtest --realsense --depth --target index_tip
.\ultrasound_solver\.venv\Scripts\python.exe -X utf8 MyPatterns\hand_track.py camtest --realsense --pointcloud --target index_tip
```
