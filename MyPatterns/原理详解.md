# SonicSurface 超声相控阵:控制软件原理详解

> 本文回答三个核心问题:**① 按钮式脉冲 vs 稳定发射的体感差异**,**② 相位控制方程从单点到图案的演进**,**③ 图案发射的算法与公式**。
> 基于开源项目 SonicSurface(upnalab)及其配套控制软件(NetBeans 版 AcousticFieldSim / Python 驱动)的源码与实测。

---

## 总纲:控制软件在做什么

```
┌──────────────┐   ┌──────────────┐   ┌──────────────┐   ┌────────────┐
│ 图案函数      │ → │ 量化 0..31    │ → │ 串口 254+256+253│ → │ FPGA→256路 │
│ (在PC上算相位)│   │ (硬件只有32级) │   │ (230400波特)   │   │ 换能器发射 │
└──────────────┘   └──────────────┘   └──────────────┘   └────────────┘
```

**核心事实:每颗换能器永远全幅、同频(40 kHz)发射方波,电脑唯一能控制的量是 256 个"相位"(每路 32 级,每级 11.25°)。** 所有花样——聚焦、涡旋、图案、触觉——都是靠安排这 256 个数字实现的。FPGA 不做计算,只负责按相位表精确发射(双缓冲,一条 commit 命令瞬间换图)。

### 核心物理公式(全文反复用到)

空间任意点 P 的声压是 256 路波的复数叠加:

```
p(P) = Σᵢ  Aᵢ(P) · e^{ j( φᵢ + k·dᵢ(P) ) }
        │      └────────┬────────┘
        │         相位项(唯一可挖的变量)
        └ 活塞指向性 × 1/d 衰减(物理决定,不可控)
```

- φᵢ:第 i 个换能器的**发射相位**(我们设的)
- k = 2π/λ,λ = 8.65 mm(40 kHz 空气声波):波每走一个 λ,相位转一圈
- dᵢ(P):换能器 i 到 P 的距离(几何决定)

**波相遇时同相相加、反相相消**——控制 φᵢ 就是控制"哪里叠加、哪里抵消"。

## 问题 1:为什么按钮式脉冲的气流范围更广、感觉更强?

### 1.1 先澄清:两种模式发射的超声"本身"完全一样

板子每一微秒发出的都是同样的全幅 40 kHz 方波。区别只在**时间轴上图案是常驻还是被 200 Hz 反复装卸**:

```
稳定(悬浮)模式: ████████████████████████  ← 图案常驻,声场恒定
按钮式(burst):  ████░░████░░░░████░░░░██  ← 同一图案,200Hz 开/关
                └70%开┘└30%关┘   (占空比 duty = 0.7)
```

实现方式:软件先把"焦点图"和"全关图"预装进 FPGA 的**双缓冲**(两块缓冲区),之后每发**一个字节(253,43 µs)**就让前后台瞬间互换——绕开整帧发送 11 ms 的耗时,轻松做到 200 Hz 开关。稳定模式则只装一次图便撒手不管。

### 1.2 为什么"感觉"的范围更广:能量守恒 + 手掌很大

**悬浮模式的"气流范围"其实一点也不小——只是你没有把手伸进声柱里细感知。** 声波要到达 12 cm 处的焦点,必须先"路过"中间的每一厘米。穿过任何高度的横截面的**总功率近似相等**(能量不会中途消失),变的只是摊多大面积:

| 高度 | 光斑直径 | 该处峰值声压 | 手掌(±4 cm)接住的总声强 |
|---|---|---|---|
| 6 cm | ~16.8 cm | 16% | ~10% |
| 8 cm | ~3.8 cm | 19% | ~17% |
| 10 cm | ~0.8 cm | 56% | ~52% |
| **12 cm(焦点)** | **~0.7 cm** | **100%** | **100%** |
| 15 cm | (发散中) | ~41% | ~39% |

也就是说,从阵面到焦点是一条**收拢的能量漏斗**——悬浮时泡沫球(3 mm)只能停在强度密度最高的焦点,但**你的手掌有 8 cm 大**,放在漏斗任何高度都能接到可观的总功率,都会有"风"。

**burst 模式气流范围显得更广的三个原因:**

1. **峰值脉冲激发声流**:开→关的瞬态让声流(streaming,超声在空气中被吸收转化成的稳态气流)更强、更"冲",沿整条声柱都能被皮肤感知为风;
2. **瞬态宽度**——皮肤对"变化"极其敏感(快适应感受器),200 Hz 的每一次"开"都是一次冲击,漏斗里每一处都因此被感知到,而稳定模式各处只有恒定值,神经系统适应后忽略;
3. **可闻声耦合**:200 Hz 包络被解调成可听低鸣,同时敲击手掌,进一步放大"整片有东西"的印象。

### 1.3 为什么 200 Hz 的气流"更强":不是能量更大,是皮肤只听得懂这个频率

先看能量账:**burst 平均功率只有稳定模式的 70%(duty)**——论真实平均气流,burst 反而**更弱**。体感变强全靠"翻译":

手掌的力学感受器各有频段:

| 感受器 | 敏感频段 | 对恒定超声束 |
|---|---|---|
| **环层小体(Pacinian)** | **20~500 Hz,峰值约 250 Hz** | 40 kHz 超出带宽 100 倍 → 无响应 |
| 迈斯纳小体 | 5~50 Hz 颤动 | 无响应 |
| 默克尔细胞 | 直流~5 Hz | 唯一能感到恒定辐射压的,阈值很高且很快适应 |

稳定模式作用在手上的只有 40 kHz 振动(皮肤"听不见")+ 恒定辐射压(被适应机制过滤,就像你感觉不到衣服压身)。**200 Hz 调制把恒定辐射压变成了 200 Hz 振荡——不偏不倚落在环层小体最敏感点上,它灵敏到能感知亚微米振动,比静态压力感知敏感约两个数量级。**

**类比**:手机振动电机。匀速转着压在你手上,几秒就无感;让它按振动铃声的节奏啪啪打你,感觉强烈。力没变大,是**节拍对了**。这也是论文专门做 200 Hz 调制固件(FPGATactileModulation)、整个超声触觉领域都靠幅度调制的原因——先把格式改对,一瓦顶十瓦。

> 附:200 Hz 调制会听到低鸣,因为触觉频段(20~1000 Hz)完全落在听觉频段(20 Hz~20 kHz)内——同一束波,皮肤感到多少,耳朵原则上就听到多少。想要安静可降调制频率(嗡声 ∝ f²,40 Hz 时低 ~28 dB)或改用单击脉冲。

## 问题 2:相位控制方程——从单点到多点再到图案

### 2.0 硬件怎么"调控每一个超声波发射器"

你问的"调控每一个发射器"——**唯一通道就是串口发去的 256 字节**。每字节 0~31 表示该换能器把 40 kHz 方波的起点**推迟多少个 1/32 周期**(32 = 关闭该阵元)。FPGA 里每个通道有个信号发生器模块(PhaseLine):全局 40 kHz 计数器从 0 数到 31 循环,当计数器走到"自己存的相位值"那一刻输出翻转——于是每路方波错开了设定的相位。就这样,256 个数字 = 256 个延迟量,没有更多了。

### 2.1 单点聚焦:有公式,一步解出

想让 P 点所有波同相 → 每个换能器的发射相位**补掉路程差的小数部分**:

```
φᵢ = 2π · ( ⌈dᵢ/λ⌉ − dᵢ/λ )   (mod 2π)
      └── 到下一个整数波长的差 ──┘
```

**代数字**:两个换能器到 P 分别是 0.160 m(18.497λ)和 0.163 m(18.844λ):

| 换能器 | d/λ | 小数部分 | 设的发射相位 | 到达时:路上圈数 + 预转圈数 |
|---|---|---|---|---|
| A | 18.497 | 0.497 | 0.503 圈 = 181° | 19.000 ✓ 整数,同向 |
| B | 18.844 | 0.844 | 0.156 圈 = 56° | 19.000 ✓ |

256 路全部这样"对表"→ P 点同相叠加,声压 ≈ 256 倍单路。**聚焦距离就是目标点坐标的一部分**——改 `--dist` 就是改 P 的 y 坐标,重算一副 256 相位表,焦点就挪走。

为什么这么轻松?因为"同向"是宽松条件:只要求 256 支箭头指向**同一个**方向,不限定哪个方向。

### 2.2 两点聚焦:精确解突然不存在了

同时对 P₁、P₂ 聚焦,每个换能器要同时满足:

```
φᵢ + k·dᵢ(P₁) ≡ α₁ (mod 2π)     ← 到 P₁ 时同向
φᵢ + k·dᵢ(P₂) ≡ α₂ (mod 2π)     ← 到 P₂ 时同向
```

两式相减消去 φᵢ,得到硬性关卡:

```
α₂ − α₁ ≡ k·[ dᵢ(P₂) − dᵢ(P₁) ]  (mod 2π)   必须对全部 256 个 i 同时成立
```

但 `dᵢ(P₂) − dᵢ(P₁)` 是"每个换能器到两点的路程差",**每个都不一样**(几何决定,改不了);左边却是一个定数。要求一个定数等于 256 个各不相同的数——**一般做不到**。

这就是"方程解不出来"的准确含义:**不是算不动,是精确解根本不存在**。256 个自由度看着多,但要同时精确命中 2 个点(更别提 4096 个像素),立刻入不敷出——像 256 根橡皮筋,拴 2 个锚点勉强,拴 4096 个必然互相拉扯。

### 2.3 多点:解不存在,那就"凑"——交替投影(迭代反传播 IBP)

退而求**最优近似**,思路朴素得像和面:

```
初始化: xᵢ = e^{jφᵢ}(随便猜一副相位)

循环 ~20 次:
  ① 正传    f = Gᵀ x        按当前相位算出 P₁..Pₘ 现在的样子(复数场)
  ② 点端硬改 f ← f/|f|      各目标点幅度掰成 1,相位保留     ← "我要什么"
  ③ 反传    x = G* f        共轭转置 = 声学时间倒流,回阵面
  ④ 阵面硬掰 x ← x/|x|      强制等幅(硬件只认纯相位!)      ← "我只能做什么"
```

G 是**传播矩阵**:G[i,p] = 换能器 i 在目标点 p 处产生的复数场(活塞模型,含指向性 sinc、1/d 衰减、e^{jkd} 传播相位)。G 的共轭转置 G* 在数学上恰好是"时间倒流"的传播。

每一轮先满足一头、牺牲另一头,再反过来补救。来回拉扯中,两头被破坏的部分越来越小——**交替投影法的收敛性是有定理保证的**(每轮投影后到可行集的距离不增)。20 轮后两头各自都只差一点点——这个"双方都能接受"的解就是答案。

软件里的实现(官方 `SonicSurface.py` 的 `multiFocusIBP`,NetBeans 软件的 `SimpleIB`,以及自制脚本的 `phases_multipoint`)都是这四步,矩阵运算一共几行。耗时 **0.2 ms**,完全实时。多点还支持给每个点指定**相对幅度**(点的第 4 列参数)——这就是未来做力度分级的一个抓手。

### 2.4 一句话总结演进逻辑

> **单点** → 条件宽松,有闭式公式 → **多点** → 各换能器到各点的路程差互不相同,一个 φᵢ 塞不进所有条件,**精确解不存在** → 只能求**近似** → 交替投影:两头轮流硬掰,误差越捏越小 → **图案** = 同一个捏法,约束从"几个点"换成"一整张图的 4096 个像素"。

## 问题 3:图案是怎么发射出来的?方程是什么

### 3.1 图案 = 多点算法把"约束"换成一整张图

和 2.3 是**同一个算法(Gerchberg–Saxton 交替投影),只改步骤②**:

| 目标类型 | 步骤②"硬改"改成什么 |
|---|---|
| 2 个点 | P₁、P₂ 两处幅度 = 1 |
| m 个点 | m 个点幅度 = 各自指定值 |
| **图案** | **64×64 = 4096 个像素,幅度 = 图片的明暗值 T(P)** |

```
循环 50 次:
  ① 正传     f = Gᵀ x          阵面 → 目标切面
  ② 目标约束  f ← T · f/|f|     幅度盖成图片明暗 T,相位保留   ← 在这里"画图"
  ③ 反传     x = G* f          切面 → 阵面
  ④ 阵面约束  x ← x/|x|         回到单位圆(等幅!纯相位!)    ← 在这里守硬件限制
最后: φᵢ = angle(xᵢ),量化成 0..31 发给板子
```

**为什么必须迭代、且效果有上限**:约束数(4096)远超自由度(256 个相位),且硬件锁死等幅(|xᵢ| 必须恒为 1)——想直接控幅度,但相位只能间接影响幅度,是非线性问题。交替投影保证收敛,但收敛点是"双方妥协"的近似:图案重建的均方误差(MSE)典型在 0.03~0.05,亮区边缘带斑点(speckle)。

### 3.2 两版实现(都保留在自制脚本里)

**论文原版(method='paper',SonicSurface 论文 §4)**:把阵列当**连续口径**,用**角谱法**(FFT 域传播)正/反传,中间把场下采样到换能器网格、量化相位/幅度再上采样回连续面。问题:设计模型(连续、带角谱低通滤波)≠ 真实物理(256 个离散活塞直接干涉),对这种失配纯相位干涉极其敏感——实测物理重建与目标的相关系数只有 ~0.19,斑点很重。

**阵列感知版(method='array',自制改进)**:传播矩阵 G 直接用**实测的 256 个换能器坐标 + 活塞模型**构建——**设计用的物理 = 真实物理**,迭代天然对准真实声场。实测字母 F 的物理重建相关系数 **0.19 → 0.91**,笑脸 0.90。这是"设计模型必须与物理一致"的直观教训。

### 3.3 从"网格解"到"实际通道":最近邻映射

迭代得到的是 16×16 理想网格上的一副相位(按行主序展开 256 个)。真实换能器的坐标是实测的(有亚毫米安装误差),用**最近邻匹配**把每个理想网格单元分配给离它最近的实际通道:

```
ch[g] = argmin_c ‖理想位置_g − 实测位置_c‖     (256 对 256 的一一匹配)
phases[ch[g]] = ph_grid[g]                     注意方向:ch 是"取址",要"放值"
```

(注意此处易错:必须 `phases[ch] = 值`,写反成 `值[ch]` 会把图案按错误的换位打乱——实测踩过的坑。)

### 3.4 图案方向约定

图片"上" = +z,"右" = +x(从阵列法线方向俯视)。镜像/颠倒时用翻转参数修正。

### 3.5 图案的感知与验证

- **图案天生带"柱面背景"**(见问题 1.2 的能量漏斗)且能量摊薄(单焦点全部能量集中 ~1 cm²,图案摊到几十 cm²,单位面积强度低 1~2 个数量级)——所以**静态图案手掌几乎无感**,要"摸到"必须加 200 Hz 调制,要传形状最好用"顶点布点 + 焦点描边"而非填充图案;
- 验证图案的标准手段是**麦克风扫描**(论文图 8)或**悬浮颗粒**,不是手掌。

## 附:三类目标的统一视图

| 目标 | 求 256 个 φᵢ 的方式 | 耗时 | 特点 |
|---|---|---|---|
| 焦点/涡旋/双阱 | 几何公式(路程补数 + 相位签名) | ~0.1 ms | 解析解,只对相位提要求 |
| 多点 | 交替投影,约束 = m 个点 | 0.2 ms | 精确解不存在,迭代逼近 |
| 图案 | 同一交替投影,约束 = 整张图 | ~100 ms | 妥协最大,带斑点 |
| 调制(burst) | **不改任何 φᵢ**,只把相位表按 200 Hz 装卸 | — | 形状轴与时间轴独立 |

**贯穿全文的一句话**:形状靠相位(空间轴),力度与感知靠时间(调制轴)——两根轴独立,机器人触觉里可以分开调。
