# SonicSurface 超声相控阵:控制软件原理详解

> 本文回答三个核心问题:**① 按钮式脉冲 vs 稳定发射的体感差异**,**② 相位控制方程从单点到图案的演进**,**③ 图案发射的算法与公式**。
> 基于开源项目 SonicSurface(upnalab)及其配套控制软件(NetBeans 版 AcousticFieldSim / Python 驱动)的源码与实测。公式均给出推导,数值均经仿真或实板核验。

---

## 总纲:控制软件在做什么

```
┌──────────────┐   ┌──────────────┐   ┌──────────────┐   ┌────────────┐
│ 图案函数      │ → │ 量化 0..31    │ → │ 串口 254+256+253│ → │ FPGA→256路 │
│ (在PC上算相位)│   │ (硬件只有32级) │   │ (230400波特)   │   │ 换能器发射 │
└──────────────┘   └──────────────┘   └──────────────┘   └────────────┘
```

**核心事实:每颗换能器永远全幅、同频(40 kHz)发射方波,电脑唯一能控制的量是 256 个"相位"(每路 32 级,每级 11.25°)。** 所有花样——聚焦、涡旋、图案、触觉——都是靠安排这 256 个数字实现的。FPGA 不做计算,只负责按相位表精确发射(双缓冲,一条 commit 命令瞬间换图)。

### 核心物理公式(全文反复用到)

先固定记号:N = 256 个换能器,位置 rᵢ = (xᵢ, yᵢ, zᵢ),阵列位于 y = 0 平面;工作频率 f₀ = 40 kHz,波长 λ = c/f₀ ≈ 8.65 mm(25 °C,c = 346 m/s),波数 k = 2π/λ。

每路发射的是等幅方波,但换能器是窄带器件(机械品质因数 Q 高),方波中的三次及以上谐波被机械滤波掉,只留基频——所以声学上可以按**等幅单频活塞**处理。第 i 路在空间一点 P 产生的复声压:

```
pᵢ(P) = Aᵢ(P) · e^{ j( φᵢ + k·dᵢ(P) ) }          dᵢ(P) = |P − rᵢ|

Aᵢ(P) = D(θᵢ) / dᵢ          D(θ) = sinc( (π a / λ)·sinθ )      a = 9 mm(活塞口径)
```

- **φᵢ**:第 i 路的发射相位——**全文唯一可挖的变量**
- θᵢ 是 P 相对换能器轴线的偏轴角;D(θ) 是活塞指向性,来自活塞面上连续分布子波的积分(数学上就是单缝衍射公式)——它说明换能器不能把声能发到侧面:偏轴 40° 时 D 已衰减到约 0.41
- 1/dᵢ 是几何衰减

声压远小于大气压时声学方程可线性化(空气中小振幅超声成立),总场是**线性叠加**:

```
p(P) = Σᵢ₌₁^N pᵢ(P) = Σᵢ Aᵢ(P) · e^{jφᵢ} · e^{jkdᵢ}
```

时间平均声强 I ∝ |p(P)|²。**控制问题的一般表述:求 {φᵢ},使 |p(P)|² 的空间分布逼近给定目标。** 下文三个问题都是这一个问题的不同特例。

**波相遇时同相相加、反相相消**——控制 φᵢ 就是控制"哪里叠加、哪里抵消"。

## 问题 1:为什么按钮式脉冲的气流范围更广、感觉更强?

### 1.1 先澄清:两种模式发射的超声"本身"完全一样

板子每一微秒发出的都是同样的全幅 40 kHz 方波。区别只在**时间轴上图案是常驻还是被 200 Hz 反复装卸**:

```
稳定(悬浮)模式: ████████████████████████  ← 图案常驻,声场恒定
按钮式(burst):  ████░░████░░░░████░░░░██  ← 同一图案,200Hz 开/关
                └70%开┘└30%关┘   (占空比 duty = 0.7)
```

实现方式:软件先把"焦点图"和"全关图"预装进 FPGA 的**双缓冲**(两块缓冲区),之后每发**一个字节(253,43 µs)**就让前后台瞬间互换——绕开整帧发送 11 ms 的耗时,轻松做到 200 Hz 开关。稳定模式则只装一次图便撒手不管。

### 1.2 为什么"感觉"的范围更广:能量守恒 + 手掌很大

**悬浮模式的"气流范围"其实一点也不小——只是你没有把手伸进声柱里细感知。** 声波要到达 12 cm 处的焦点,必须先"路过"中间的每一厘米。穿过任何高度的横截面的**总功率近似相等**(能量不会中途消失,线性介质无吸收),变的只是摊多大面积:

| 高度 | 光斑直径 | 该处峰值声压 | 手掌(±4 cm)接住的总声强 |
|---|---|---|---|
| 6 cm | ~16.8 cm | 16% | ~10% |
| 8 cm | ~3.8 cm | 19% | ~17% |
| 10 cm | ~0.8 cm | 56% | ~52% |
| **12 cm(焦点)** | **~0.7 cm** | **100%** | **100%** |
| 15 cm | (发散中) | ~41% | ~39% |

也就是说,从阵面到焦点是一条**收拢的能量漏斗**——悬浮时泡沫球(3 mm)只能停在强度密度最高的焦点,但**你的手掌有 8 cm 大**,放在漏斗任何高度都能接到可观的总功率,都会有"风"。

**burst 模式气流范围显得更广的三个原因:**

1. **峰值脉冲激发声流**:开→关的瞬态让声流(streaming,超声在空气中被吸收转化成的稳态气流)更强、更"冲",沿整条声柱都能被皮肤感知为风;
2. **瞬态敏感**:皮肤对"变化"极其敏感(快适应感受器),200 Hz 的每一次"开"都是一次冲击,漏斗里每一处都因此被感知到,而稳定模式各处只有恒定值,神经系统适应后忽略;
3. **可闻声耦合**:200 Hz 包络被解调成可听低鸣,同时敲击手掌,进一步放大"整片有东西"的印象。

### 1.3 为什么 200 Hz 的气流"更强":不是能量更大,是皮肤只听得懂这个频率

先看能量账:**burst 平均功率只有稳定模式的 70%(duty)**——论真实平均气流,burst 反而**更弱**。体感变强全靠"翻译"。

手掌的力学感受器各有频段(生理学事实,非比喻):

| 感受器 | 敏感频段 | 对恒定超声束 |
|---|---|---|
| **环层小体(Pacinian)** | **20~500 Hz,峰值约 250 Hz** | 40 kHz 超出带宽 100 倍 → 无响应 |
| 迈斯纳小体 | 5~50 Hz 颤动 | 无响应 |
| 默克尔细胞 | 直流~5 Hz | 唯一能感到恒定辐射压的,阈值很高且很快适应 |

稳定模式作用在手上的只有 40 kHz 振动(皮肤"听不见")+ 恒定辐射压(被适应机制过滤,就像你感觉不到衣服压身)。**200 Hz 调制把恒定辐射压变成了 200 Hz 振荡——不偏不倚落在环层小体最敏感点上,它灵敏到能感知亚微米振动,比静态压力感知敏感约两个数量级。**

**类比**:手机振动电机。匀速转着压在你手上,几秒就无感;让它按振动铃声的节奏啪啪打你,感觉强烈。力没变大,是**节拍对了**。这也是论文专门做 200 Hz 调制固件(FPGATactileModulation)、整个超声触觉领域都靠幅度调制的原因——先把格式改对,一瓦顶十瓦。

> 附:200 Hz 调制会听到低鸣,因为触觉频段(20~1000 Hz)完全落在听觉频段(20 Hz~20 kHz)内——同一束波,皮肤感到多少,耳朵原则上就听到多少。想要安静可降调制频率(嗡声 ∝ f²,40 Hz 时低 ~28 dB)或改用单击脉冲。

## 问题 2:相位控制方程——从单点到多点再到图案

### 2.0 硬件怎么"调控每一个超声波发射器"

你问的"调控每一个发射器"——**唯一通道就是串口发去的 256 字节**。每字节 0~31 表示该换能器把 40 kHz 方波的起点**推迟多少个 1/32 周期**(32 = 关闭该阵元)。这句话背后是一套很具体的硬件机制,拆开讲:

**背景:FPGA 输不出正弦波,只能输出高/低两种电平。**"发 40 kHz 方波"= 让某个引脚每 25 µs 完成一次"高 12.5 µs + 低 12.5 µs"。问题变成:怎么让 256 个引脚各自精确地**错开时间**开始高电平?

**① 全局计数器——全板共用的钟表。** FPGA 内部有一枚 10.24 MHz 快时钟,一个所有通道共享的计数器对它计数,从 0 数到 31 后归零循环:

```
快时钟: ├─┤├─┤├─┤├─┤…          每格 97.65 ns
计数器:  0  1  2 3 … 30 31 | 0  1  2 … 31 | 0 …
         └── 一轮 32 步 = 25 µs = 恰好一个 40 kHz 周期 ──┘
```

数满一轮正好等于一个声周期,所以**任何时刻问"现在是这个周期的第几步",256 个通道的答案完全一致**。它是全板唯一的节拍器(对应固件里的 Counter.vhd + Masterclock)。

**② 每个通道的"输出翻转"规则。** 每个引脚只遵守两条规则(这就是固件里的 PhaseLine.vhd):

```
计数器数到【我的相位值】    → 引脚翻成高电平
计数器数到【我的相位值+16】 → 引脚翻成低电平     (16 = 半周期,保证高低各半)
```

"我的相位值"就是串口发来的那个字节,存在各通道自己的寄存器里。引脚平时什么都不做,只在计数器扫过这两个预订时刻"动一下"——方波不是生成的,是**在时间轴上预订两个翻转时刻、到点自动翻**出来的。

**③ 为什么这样就"错开了相位"。** 设串口发来通道 A = 0、B = 8,跟踪一个周期:

```
计数器:  0    2    4    6    8   10  …  16   18  …  24  …  31 → 0
A引脚:   ▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▁▁▁▁▁▁▁▁▁▁▁▁▁▁▔▔   A:计0翻高,计16翻低
B引脚:   ▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▔▔▔▔▔▔▔▔▔▔▔▔▁▁▁▁▁▁▁▁   B:计8翻高,计24翻低
```

B 的高电平比 A **晚了 8 步 = 8/32 周期 = 6.25 µs = 90°**。相位差就是时间差:一个周期 25 µs 对应 360°,所以

```
延迟时间 = (相位值/32) × 25 µs          相位角 = (相位值/32) × 360°
```

发一个数字 n,FPGA 不做任何计算,只是让那个引脚的翻转时刻在时间轴上平移 n 步。**256 个字节 = 256 套独立的翻转时刻表。**

**④ 与聚焦公式的衔接。** 电脑算出 φᵢ(弧度),量化成 nᵢ = round(φᵢ/2π×32) 发给板子;板子上 nᵢ 步延迟 = nᵢ×25µs/32 的推迟发射,正好抵消换能器 i 到焦点路程差造成的时间差,波峰对齐。完整链条:

```
电脑算相位(弧度) → 量化 0..31 → 串口 → FPGA 存入各通道寄存器
  → 全局计数器扫到各自数值时翻转引脚 → 波形错开 → 空气中干涉
```

三个此前埋下的伏笔在此闭环:为什么"32 = 关闭"?32 超出 0~31 的计数范围,模块识别后干脆不翻转,引脚保持低电平,该换能器静默。双缓冲为何能"瞬间换图"?新旧两套寄存器只在计数器**每轮归零(周期边界)**的一瞬切换读哪套——换图发生在周期之间,不会出现半个旧周期拼半个新周期的杂交波形。为什么相位分辨率是 32 级?10.24 MHz = 40 kHz×32,一个声周期恰好切 32 步;想更细则需要更高时钟(64 级要 >20 MHz,普通两层 PCB 走线就吃不消了)。

### 2.1 单点聚焦:方程有解,而且是"解族"

目标:让 P₀ 点声压最大,即 maximize |p(P₀)|。由**三角不等式** |Σⱼ zⱼ| ≤ Σⱼ |zⱼ|,等号成立当且仅当所有 zⱼ **同相**——所以最优解就是让每一项辐角相等:

```
φᵢ + k·dᵢ(P₀) ≡ α  (mod 2π)   ∀i        α 任意
⇒  φᵢ = α − k·dᵢ(P₀)  (mod 2π)
```

α 任意对应一个物理事实:所有通道整体加同一个相位,只是移动时间原点,声场分布不变——解是**单参数族**,没有观测意义上的区别。代码取 α = 0 并折进 [0, 2π):

```
φᵢ = −k·dᵢ (mod 2π) = 2π · ( ⌈dᵢ/λ⌉ − dᵢ/λ )
```

**验证后一个等式**:设 dᵢ/λ = n + f(n 为整数,f ∈ [0,1)),则 −k·dᵢ (mod 2π) = 2π(1−f),而 ⌈dᵢ/λ⌉ − dᵢ/λ = (n+1) − (n+f) = 1−f。两者一致——**代码里的 `ceil` 不是数值技巧,是 mod 运算的解析实现。**

此时 p(P₀) = Σᵢ Aᵢ(P₀),各路**幅度**直接相加。若各路幅度近似相等,|p(P₀)| ≈ 256·A,声强 ≈ 256² 倍单路——这是**相干增益**;若各路相位随机,声强只有 256 倍(非相干叠加)。两者差 256 倍,这就是聚焦的全部意义。

**代两个具体数字**:换能器 A、B 到 P 分别为 0.160 m(18.497λ)和 0.163 m(18.844λ):

| 换能器 | d/λ | 小数部分 f | 设的发射相位 = 2π(1−f) | 到达时:路上圈数 + 预转圈数 |
|---|---|---|---|---|
| A | 18.497 | 0.497 | 0.503 圈 = 181° | 19.000 ✓ 整数,同向 |
| B | 18.844 | 0.844 | 0.156 圈 = 56° | 19.000 ✓ |

256 路全部这样"对表"→ P 点同相叠加。**聚焦距离就是目标点坐标的一部分**——改 `--dist` 就是改 P 的 y 坐标,重算一副 256 相位表,焦点就挪走。

**为什么单点这么轻松?** 因为"同向"是宽松条件:只要求 256 支箭头指向同一个方向,不限定哪个方向(这个自由度正是上面的 α)。

**涡旋、双阱是单点解的解析推广**——在解出的 φᵢ 上叠加"相位签名":

```
涡旋: φᵢ ← φᵢ + m·ψᵢ          ψᵢ = atan2(xᵢ−x_c, zᵢ−z_c)(绕阵列中心的方位角)
双阱: φᵢ ← φᵢ + π·𝟙[cos(ψᵢ+θ₀) < 0]     (按方位角劈成两半,一半加 π)
```

涡旋签名使波前成为螺旋面:绕轴一圈相位累积 2mπ。轴线上各方向来波的相位连续覆盖整个 2π,因此**在轴上必然完全相消**——更严格地说,携带拓扑荷 m 的场在轴上是相位奇点,场的正则性强制幅度为零(这也是"携带轨道角动量"的数学表述)。这些签名仍然是闭式,因为它们只约束**相位**;一旦约束落到**幅度**上,就必须转入下面的迭代法。

### 2.2 两点聚焦:精确解不存在——可以证明

同时对 P₁、P₂ 聚焦,理想条件是每点都达到 2.1 的同相叠加,即要求存在一组 {αₚ} 使:

```
φᵢ + k·dᵢ(P₁) ≡ α₁  (mod 2π)      ← 到 P₁ 时同向
φᵢ + k·dᵢ(P₂) ≡ α₂  (mod 2π)      ← 到 P₂ 时同向
```

两式相减消去 φᵢ,得到硬性关卡:

```
k·[ dᵢ(P₁) − dᵢ(P₂) ] ≡ α₁ − α₂  (mod 2π)      必须对全部 256 个 i 同时成立
          └────── Δᵢ:第 i 路到两焦点的路程差 ──────┘
```

左边 Δᵢ 随 i 变化(每个换能器位置不同,到两点的路程差不同,**几何决定,改不了**);右边却是与 i 无关的常数。无解条件很宽:只要存在两路 i, j 使 k·(Δᵢ − Δⱼ) ≢ 0 (mod 2π)——即 |Δᵢ − Δⱼ| 不是 λ 的整数倍——方程就无解。几何上 Δᵢ 随换能器位置连续变化,而 λ = 8.65 mm 远小于阵列尺度 168 mm(阵元间距 10.5 mm 都有 1.21λ),上式几乎必然成立——**除极特殊对称构型外,m ≥ 2 的精确解不存在。**

这就是"方程解不出来"的准确含义:**不是算不动,是精确解根本不存在**。256 个自由度看着多,但要同时精确命中 2 个点(更别提 4096 个像素),立刻入不敷出——像 256 根橡皮筋,拴 2 个锚点勉强,拴 4096 个必然互相拉扯。

顺带说明 Checker 法(官方 `multiFocusChecker`)是怎么绕的:它放弃"每点满幅",按 (i mod m) **分组**,第 i 路只负责第 (i mod m) 个焦点,各组单独满足自己焦点的同相条件——方程永远可解,代价是每点声压降为约 1/m(相干增益 N² → (N/m)²),且组间失配产生旁瓣。IBP 则不分组,全体换能器服务所有点。

### 2.3 多点:解不存在,那就"凑"——交替投影(IBP)的完整机制

退而求**最优近似**。先把问题写成约束满足问题的标准形,定义两个集合:

```
𝒜 = { x ∈ ℂ²⁵⁶ : |xᵢ| = 1 ∀i }            可行阵面集(等幅/纯相位约束,硬件决定)
ℬ = { Gx 的幅度模式满足目标 }                目标场集
```

其中 G 是**传播矩阵**(256×m 复矩阵,固定,一次算好):G[i,p] = Aᵢ(Pₚ)·e^{jkdᵢ(Pₚ)}——就是核心公式里每路到每点的复数贡献。我们要找 x ∈ 𝒜 使 Gx 尽量接近 ℬ。2.2 已证两集合一般**不相交**,只能求最近点。迭代:

```
初始化: xᵢ = e^{jφᵢ}(随机初相)

循环 ~20 次:
  ① 正传     f ← G x           按当前相位算出 P₁..Pₘ 现在的样子(线性,精确)
  ② 点端硬改 f ← f / |f|       各目标点幅度掰成 1,相位完全保留    ← "我要什么"
  ③ 反传     x ← Gᴴ f          共轭转置 = 声学时间倒流,回阵面
  ④ 阵面硬掰 x ← x / |x|       强制等幅(硬件只认纯相位!)        ← "我只能做什么"
```

**每一步的确切含义:**

- **②** `f/|f|`:把各分量归一到模 1。这是到"等幅点集"的**欧氏最近点投影**——幅度硬改、相位不动,是改动量最小的方式。(给每点指定目标幅度 aₚ 时改成 `f·(aₚ/|fₚ|)`,迭代结构不变——这就是多点力度的抓手。)
- **③** Gᴴ(共轭转置)为何是"反传":G 的元素含 e^{+jkd},共轭转置后变 e^{−jkd}——正是往回走的传播算子。严格说,从 f 反推最小二乘最优 x 应为 x = (GᴴG)⁻¹Gᴴf;GS 略去 (GᴴG)⁻¹(该矩阵近似对角占优,略去相当于每路独立取最简回传),换来每步只是矩阵乘法。
- **④** `x/|x|`:到单位圆环面 𝒜 的逐分量最近点投影(辐角不动、模拉回 1)。

**收敛性(诚实版)**:若两个集合都是凸集,交替投影收敛到最小距离点对(1930 年代起的定理体系)。这里 𝒜 是环面(**非凸**),ℬ 也非凸,所以只能保证**距离不增**——每步投影不会让解离目标更远,但不保证收敛到全局最优。实践中 GS 靠随机初相重试躲避坏的局部解,这也解释了换随机种子偶尔得到略不同的结果。实测 20 轮内残差基本饱和。

**耗时**:①③ 是 256×m 复矩阵乘向量(m=3 时约 2×10⁵ 次浮点运算),NumPy 走 BLAS,单次全迭代 **0.2 ms**——完全实时。官方 `SonicSurface.py` 的 `multiFocusIBP`、NetBeans 软件的 `SimpleIB`、自制脚本的 `phases_multipoint` 都是这四步。

### 2.4 一句话总结演进逻辑

> **单点** → 条件宽松(三角不等式等号),有闭式公式 → **多点** → 各换能器到各点的路程差互不相同,一个 φᵢ 塞不进所有条件,**精确解不存在** → 只能求**近似** → 交替投影:两头轮流硬掰,距离不增 → **图案** = 同一个捏法,约束从"几个点"换成"一整张图的 4096 个像素"。

## 问题 3:图案是怎么发射出来的?方程是什么

### 3.1 图案 = 多点算法把"约束"换成一整张图

和 2.3 是**同一个算法(Gerchberg–Saxton 交替投影),只改步骤②**——把"m 个焦点"换成"切面网格上的 M = 64×64 = 4096 个采样点",集合 ℬ 变成:

```
ℬ = { Gx : |(Gx)ₚ| = T(Pₚ)  ∀p∈网格 }      T = 目标图(明暗归一化),G 变为 256×4096
```

| 目标类型 | 步骤②"硬改"改成什么 |
|---|---|
| 2 个点 | P₁、P₂ 两处幅度 = 1 |
| m 个点 | m 个点幅度 = 各自指定值 |
| **图案** | **4096 个像素,幅度 = 图片明暗 T(P)** |

```
循环 50 次:
  ① 正传     f ← G x           阵面 → 目标切面
  ② 目标约束  f ← T ⊙ (f/|f|)   ⊙ 为逐元素乘:幅度盖成图片明暗 T,相位保留  ← 在这里"画图"
  ③ 反传     x ← Gᴴ f          切面 → 阵面
  ④ 阵面约束  x ← x/|x|         回到单位圆(等幅!纯相位!)                ← 在这里守硬件限制
最后: φᵢ = angle(xᵢ),量化成 0..31 发给板子
```

这个算法叫 **Gerchberg–Saxton(1972)**,原本解决光学/X 射线晶体学中"两个平面各已知幅度、求相位分布"的问题——此处恰好同构:阵面已知幅度(全 1),切面想要幅度(T),来回搬运的只有相位。**多点 IBP 是它在 M 个离散点上的退化情形:两者在数学上是同一个算法,只是约束集合不同。**

**完整可运行实例**(即自制脚本 `_gs_array_phases` 的主体,逐行注释对应上面的四步):

```python
import numpy as np
from PIL import Image

N, LAM, K = 256, 0.00865, 2*np.pi/0.00865     # 阵元数 / 波长 / 波数
DIST, RES, HALF = 0.16, 64, 0.084             # 目标切面距离 / 分辨率 / 半宽

# ---------- 准备目标图案 T(64×64 明暗图) ----------
target = np.asarray(Image.open('demo_F.png').convert('L')
                    .resize((RES, RES), Image.LANCZOS), float) / 255.0
T = target.ravel()                            # 展平成 4096 维向量,值域 [0,1]

# ---------- 构建传播矩阵 G (256 × 4096) ----------
# G[i,p] = 换能器 i 在切面采样点 p 处产生的复数声压
# 切面采样点:距阵面 DIST 处的 x-z 平面网格,行 0 对应 +z(图片"上"=+z)
u = np.linspace(-HALF, HALF, RES)
U, V = np.meshgrid(u, u[::-1])
pts = np.stack([U.ravel(), np.full(U.size, DIST), V.ravel()], axis=1)   # (4096, 3)

emitters = EMITTERS                            # (256, 3) 实测换能器坐标
diff = pts[None, :, :] - emitters[:, None, :]  # (256, 4096, 3):每路到每点的位移
d = np.linalg.norm(diff, axis=2)               # (256, 4096):距离
cosang = diff[:, :, 1] / d                     # 法线是 (0,1,0),余弦=纵向分量/d
sinang = np.sqrt(np.clip(1 - cosang**2, 0, 1))
D = np.sinc(0.5 * 0.009 * K * sinang / np.pi)  # 活塞指向性(9 mm 口径)
G = (D / d) * np.exp(1j * K * d)               # 指向性×1/d×传播相位 —— 与真实声场同一算子
GH = G.conj().T                                # 共轭转置 = 反传播(时间倒流)

# ---------- GS 主迭代 ----------
rng = np.random.default_rng(0)
x = np.exp(1j * rng.uniform(0, 2*np.pi, N))    # 阵面复激励:随机初相(模全为 1,满足约束④)
# 为什么随机?全零/全同初相对称性太强,迭代会在退化解附近打转;随机破对称,重试可躲局部最优

for it in range(50):
    f = G @ x                                  # ① 正传:阵面 → 切面 (4096 维复数场)
    f = T * (f / np.abs(f))                    # ② 目标约束:幅度盖成图片明暗 T,相位保留
    #   f/|f| 先归一成纯相位,再乘 T —— "我要什么"(在这里画图)
    #   注意暗区 T=0 → f 直接归零,强制暗区无声压(标准 GS 必须这样,
    #   若放任暗区自由会保留背景能量,实测退化为亮环)
    x = GH @ f                                 # ③ 反传:切面 → 阵面 (声学时间倒流)
    x = x / np.abs(x)                          # ④ 阵面约束:归一到单位圆(硬件等幅!)
    #   这一步执行后 ② 的成果被部分破坏 —— 交替投影的本质就是
    #   "满足一头、牺牲另一头",每轮破坏量递减,残差单调不增

# ---------- 收尾 ----------
obtained = np.abs(G @ x).reshape(RES, RES)     # 收敛后的重建幅度(评估用)
phases = np.angle(x) % (2*np.pi)               # 取辐角 = 256 个发射相位(弧度)
disc = np.rint(phases / (2*np.pi) * 32) % 32   # 量化成 0..31(§3.4:衰减仅 ~0.2%)
# 之后经最近邻映射装到实测通道(§3.3),打包 254+256字节+253 发串口
```

几个容易被问到的细节:

- **`G @ x` 为什么是正传**:把 x 看作 256 路的复激励,总场公式 p(P) = Σᵢ xᵢ·G[i,P] 正是矩阵-向量乘的定义,一次乘法同时算出全部 4096 个采样点;
- **收敛监控**:实用中每轮可算 `‖ |G@x| − T ‖` 看残差,典型 10~20 轮后趋平(继续迭代收益骤减,所以默认 50 轮);
- **初相影响**:非凸问题没有全局保证,换 seed 结果会略有差异;工程做法是跑 2~3 个 seed 取残差最小的一副;
- **计算量**:G 是 256×4096 复矩阵(8 MB),构建一次约 100 ms(逐点距离+指向性),之后每轮两次矩阵乘约 2 ms——总耗时被 G 的构建主导,这就是实测 ~100 ms/次的来源。

**为什么必须迭代、且效果有上限**:未知量 256 个相位,约束 4096 个幅度等式——方程数远超未知数,最优残差由"目标图案能否被 256 个相位组合表出"决定,高对比、细条纹的图案残差必然大。ℬ 非凸使 GS 只找局部最优;残余误差在物理场中表现为暗区残余声压与亮区边缘的斑点(speckle,干涉随机相消的颗粒背景)。实测 MSE 典型 0.03~0.05。

### 3.2 两版实现的实质差别(为什么 0.19 vs 0.91)

**论文原版(method='paper',SonicSurface 论文 §4)**:传播算子不是离散活塞,而是"连续口径 + **角谱法**"。角谱法:对平面场做 2D FFT,每个空间频率分量 (kₓ,k_z) 乘以传播因子 e^{jk_y y}(k_y = √(k²−kₓ²−k_z²)),再 IFFT——等价于把场展开为一组平面波各自传播。它对**连续面**精确,但真实阵列是 256 个离散点源;且数值实现中带一个限制在传播波数以内的低通窗——**设计时假设的场比真实场更平滑**。算出的相位在离散真实源上重演时,高频成分对不上;而纯相位干涉对失配极其敏感(两路相位差 90° 几乎完全相消,不是减半),误差被放大而非线性叠加。实测物理重建与目标的相关系数只有 ~0.19。

**阵列感知版(method='array',自制改进)**:G 直接用**实测的 256 个换能器坐标 + 活塞模型**构建——设计阶段的算子与评估/真实阶段的算子**是同一个**,失配为零,只剩 GS 自身的近似残差。实测字母 F 的物理重建相关系数 **0.19 → 0.91**,笑脸 0.90。这是"**设计模型必须与物理一致**"的定量教训。

### 3.3 从"网格解"到"实际通道":最近邻映射

GS 给出的是理想 16×16 网格上的相位;真实换能器位置有安装误差。最近邻匹配:

```
ch(g) = argmin_c ‖ q_g − r_c ‖        q_g = 理想网格点,r_c = 实测通道位置
phases[ch(g)] = φ_grid[g]
```

匹配唯一性:实测偏差(整体 ~2 mm 平移)远小于半个阵元间距。**方向必须写对**——`phases[ch] = 值` 是散射赋值(通道 ch(g) 接收 g 的相位);写反成 `值[ch]` 是花式索引取值,等于对图案做一次换位。这类 bug 在 GS 内部看不出来(内部自洽),必须用**独立物理模型重算**才能暴露——这也是用无对称性的字母 F 做数值判定的原因。

### 3.4 量化误差的账

最终 φᵢ 量化到 32 级:φ̂ᵢ = round(φᵢ/2π·32)·(2π/32),每路最大误差 π/32 = 5.6°。量化噪声近似均匀分布,相位误差方差 σ² = (2π/32)²/12;256 路相干叠加时,相干分量按 sin(σ) ≈ σ 计算约衰减 **6%**——可感知但不致命,仍远小于 GS 残差。**32 级量化不是瓶颈**(论文图 9 的参数扫描同样表明 8 级以上收益已平)。

### 3.5 图案方向约定

图片"上" = +z,"右" = +x(从阵列法线方向俯视)。镜像/颠倒时用翻转参数修正。

### 3.6 图案的感知与验证

- **图案天生带"柱面背景"**(见 1.2 的能量漏斗)且能量摊薄(单焦点全部能量集中 ~1 cm²,图案摊到几十 cm²,单位面积强度低 1~2 个数量级)——所以**静态图案手掌几乎无感**,要"摸到"必须加 200 Hz 调制,要传形状最好用"顶点布点 + 焦点描边"而非填充图案;
- 验证图案的标准手段是**麦克风扫描**(论文图 8)或**悬浮颗粒**,不是手掌。

## 附:四类目标的统一视图

| 目标 | 数学对象 | 求解方式 | 确切性 |
|---|---|---|---|
| 焦点/涡旋/双阱 | 三角不等式等号条件 + 相位签名(拓扑约束) | 闭式解(单参数族) | 全局最优;只约束相位,幅度不受控 |
| 多点 | 两集合最近点问题(非凸) | 交替投影,约束 = m 个点 | 距离不增,局部最优;0.2 ms |
| 图案 | 同上,约束 = 整张图 | Gerchberg–Saxton | 同上;~100 ms,MSE 0.03~0.05 |
| 调制(burst) | 时间轴上的 0/1 乘子,**不触碰任何 φᵢ** | 查表 + 43 µs 换向 | 精确 |

所有层的共同起点仍是那一个叠加公式 p(P) = Σ Aᵢ e^{j(φᵢ+kdᵢ)}——一切控制问题都是:选 256 个相位,让这个和在你指定的地方大、指定的地方小。

**贯穿全文的一句话**:形状靠相位(空间轴),力度与感知靠时间(调制轴)——两根轴独立,机器人触觉里可以分开调。
